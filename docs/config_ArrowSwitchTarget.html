Config: ArrowSwitchTarget

Target objects for ArrowSwitchMulti that activate their SW_A values when ArrowSwitchMulti's state corresponds with their assigned state.

Arguments

NameTypeGamesRequired?DescriptionValues
Obj_arg0Integern/aTrue

Target Group ID: ID to be assigned to a group of four ArrowSwitchTarget objects and one ArrowSwitchMulti

    Obj_arg1Integern/aTrue

    Target State: The value from 0-3 that corresponds to ArrowSwitchMulti's state.

    • 0: 0°
    • 1: -90°
    • 2: 180°
    • 3: 90°
