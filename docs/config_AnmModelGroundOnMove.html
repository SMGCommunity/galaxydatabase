Config: AnmModelGroundOnMove

An object that begins Move animations and sends an SW_B signal when the player collides with its collision. It uses several sound effects. It can alternatively be started with SW_A. AnmModelMoveStart specifies the sound effect used when it starts moving. AnmModelMoveLoop specifies the looping sound effect that is played while it moves. AnmModelStop specifies the sound effect used when it stops moving. Furthermore, it can use several particle effects as well. Start specifies the particles used when it starts moving. EndLoop specifies the particles used after it stopped moving.
