Config: AstroCountDownPlate

An object that plays a countdown animation via code, counting down from 50 and pausing depending on the total number of collected stars. The animation pulls its colour values from BRK files titled "Green" and "Red". There is an additional "Revival" BRK used when the Comet Observatory is first entered in a playthrough. Number locations are determined via a BTK file titled "Number". Additionally plays sound effects corresponding to startSound and startLevelSound.
